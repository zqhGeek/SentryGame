# SentryGame 多场景游戏设计

## 目标

在当前空白 Unity 项目中开发一个竖屏 Android 游戏。游戏包含登录、模式选择、打地鼠、贪吃蛇四个独立场景，支持在 Unity Editor 中直接预览核心流程，并可在 Android 平台竖屏运行。

## 项目现状

- Unity 版本：6000.3.9f1。
- 当前构建场景：`Assets/Scenes/SampleScene.unity`。
- 已安装 `UGUI`、`InputSystem`、`Unity Test Framework`。
- 全局检索未发现登录、打地鼠、贪吃蛇、模式选择相关业务实现。

## 场景拆分

### LoginScene

`LoginScene` 是游戏入口。界面包含账号输入框、密码输入框、登录按钮和错误提示。当前使用固定账号密码验证，默认账号为 `admin`，默认密码为 `123456`。登录成功后切换到 `ModeSelectScene`，登录失败时停留在当前场景并显示错误提示。

### ModeSelectScene

`ModeSelectScene` 用于选择游戏模式。界面包含“打地鼠”和“贪吃蛇”两个按钮。点击“打地鼠”进入 `WhackAMoleScene`，点击“贪吃蛇”进入 `SnakeScene`。

### WhackAMoleScene

`WhackAMoleScene` 实现打地鼠玩法。游戏初始分数为 5 分。红点在画面安全区域内随机出现，玩家点击红点后红点消失并加 1 分。红点倒计时结束后自动消失，如果玩家没有点击则扣 1 分。分数降到 0 时游戏结束，显示结束提示和返回模式选择按钮。

### SnakeScene

`SnakeScene` 实现贪吃蛇玩法。地图使用固定网格。蛇持续按固定节奏自动移动。右下角提供上下左右四个方向按钮，移动端点击按钮改变方向。蛇不允许直接反向移动。食物在蛇身体以外的随机空格生成。蛇吃到食物后分数增加 1 分，并增长 1 节。蛇撞到墙壁或撞到自己身体时游戏结束，显示结束提示和返回模式选择按钮。

## 公共模块

公共模块放在共享脚本目录，避免不同场景重复实现同类逻辑。

- 场景常量：集中维护 `LoginScene`、`ModeSelectScene`、`WhackAMoleScene`、`SnakeScene` 名称。
- 登录校验：封装固定账号密码验证，便于后续替换成远程登录或本地配置。
- 游戏状态：使用清晰状态表示运行中、结束、等待开始等状态。
- 网格坐标：贪吃蛇逻辑使用整数网格坐标，避免浮点误差影响碰撞判断。

## UI 与适配

项目使用竖屏布局，Android 构建设置锁定 Portrait。Canvas 使用 `Scale With Screen Size`，参考分辨率为 `1080x1920`。所有主要操作按钮保持移动端可点击尺寸。贪吃蛇方向按钮固定在右下角，避免遮挡地图主体。Editor 预览时 Game 视图建议使用 `9:16` 或 `1080x1920`。

## 数据流

登录场景接收输入并调用登录校验。校验成功后通过场景管理切换到模式选择场景。模式选择场景只负责发起场景跳转。两个游戏场景各自初始化自己的玩法状态、分数、UI 和运行时对象。游戏结束后停止玩法更新，只保留结束 UI 和返回模式选择能力。

## 测试方案

实现时先增加功能测试，再写生产代码。

- 登录校验测试：正确账号密码通过，错误账号或密码失败。
- 打地鼠逻辑测试：点击红点加分，红点超时扣分，分数为 0 时结束。
- 贪吃蛇逻辑测试：蛇按方向移动，禁止直接反向，吃食物加分并增长，撞墙结束，撞到身体结束。
- 场景配置测试：构建配置包含四个场景，关键场景控制器和 Canvas 存在。

## 验证方案

每轮实现后执行 Unity 测试，确认功能测试通过。完成后在 Unity Editor 中进入 Play 模式验证完整流程：登录、模式选择、打地鼠结束、贪吃蛇结束、返回模式选择。Android 平台验证需要具备 Android Build Support 和可用设备或模拟器；如本机缺少打包条件，需要明确记录未验证项。
